## 《只有6》—— 独立完成的卡牌 Roguelike

以数字 **6** 为核心的卡牌构筑：用加、减、乘、除和正负号改写敌人的数字，把敌人推成 6 或 −6 才能击杀。

**已经做成能玩的垂直切片**：19 个节点（15 场战斗 + 4 家商店）、9 种怪、100 张卡（算法 31 / 禁物 32 / 效果 37）、141 条界面文案、6 张配置表；另外写了一套 20 条 headless 自检，守住配置表与工程资源的对齐、每关可通关性和存档口径。

一次具体的设计取舍：**小怪一律不带“算法抗性”，只给最终 BOSS 留 1 层**。原因是抗性会形成“这类牌完全打不动”的硬墙，而 19 个节点里原本只有 3 种怪带抗性，教学收益不划算；护盾已经足够表达“这一关得换打法”。这条口径同时写进了自检断言，防止以后改表时被破坏。

程序部分大量借助对话式 AI 工具完成；卡位规则、数值框架与关卡节奏由本人判断。

## 《牛马人门》—— 48 小时 GameJam（4 人，队长）

担任主策兼程序：撰写策划文档、编写游戏代码、带 3 名组员完成美术 / 音效 / 文本资源交付。Jam 提交版是半成品，赛后两周完善为约 15 分钟可玩原型。工程共 47 个场景文件，从场景文件反查可还原真实楼层结构（1–4 楼 + 2.5 楼 + 楼顶）。
